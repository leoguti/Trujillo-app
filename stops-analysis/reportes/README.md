| Archivo | Descripción |
|---------|-------------|

## Rutas suspendidas del GTFS

Las siguientes 5 rutas rurales se suspendieron temporalmente del GTFS por tener brechas graves sin paraderos:

- **C-15** (Prolongación 1)
- **C-30** (Circular)
- **C-31** (Principal)
- **C-32** (Secundaria)
- **C-33** (Prolongación 2)

Se reactivan cuando el municipio proporcione las ubicaciones reales de los paraderos de inicio y fin de cada ruta.
